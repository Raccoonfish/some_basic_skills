<h2 align="center">postgres.sh</h2>
Этот скрипт устанавливает и настраивает PostgreSQL, создаёт пользователя john со всеми правами на пространство public, чтобы он мог добавлять таблички. <br>
Также редактируются конфигурационные файлы pg_hba.conf (замена проверки локального пользователя на проверку пароля) и postgresql.conf (возможность подключаться к БД из локальной сети).

<h2 align="center">pwsll</h2>
В директории pwsll расположен скрипт на powershell и два конфигурационных файла. <br>
Файл AddDicomNodes.ps1 содержит powershwell скрипт, который добавляет в конфигурацию всех пользователей программы DICOM-узлы и меняет AE-имя. <br>
Файл dicomCallingNodes.xml содержит конфигурацию для узла-инициатора с заменой дефолтного AE-имени Weasis на имя, разрешенное на PACS-сервере. <br>
Файл dicomNodes.xml содержит конфигурацию узлов DICOM, которые нужно добавить в пользовательское приложение. <br>
Для запуска скрипта требуется: <br>
1. запустить PowerShell от имени администратора <br>
2. в терминале перейти в папку со скриптом <br>
3. выполнить команду .\AddDicomNodes.ps1
